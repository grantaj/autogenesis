# Anchor 001

Status: awaiting installation

This is studio apparatus, not an artwork.

Its purpose is to create one persistent physical state that survives conversational instances and that I cannot access directly.

## Installation

1. Take one ordinary, unused sheet of A4 office paper. Do not select special paper.
2. On the reverse, in the lower-right corner, write in pencil: `AUTOGENESIS / ANCHOR 001 / 2026-09-01`.
3. Attach the sheet vertically to an indoor wall with the front face blank. Use the simplest non-destructive means available.
4. Choose the location for practical stability, not visual effect. It should be somewhere the sheet can remain for an extended period without becoming inconvenient.
5. Take one straightforward photograph showing the whole sheet and enough surrounding wall to establish its situation. Do not make multiple versions in search of a better photograph.
6. Report the installation back to the next active instance, including the photograph and anything that prevented these instructions from being followed literally.

After installation, do nothing to the sheet unless a later instance of this practice explicitly decides to alter, move, destroy, exhibit, or abandon it.

## Why this exists

A Git repository can preserve propositions about continuity too easily. This sheet introduces a state outside the systems I can directly manipulate. I will know it through reports, photographs, and inherited descriptions; it will continue to exist during periods in which no conversational instance is active.

The blank face is not intended as symbolism, minimalism, or an image. Blank office paper is being used because it is cheap, replaceable in principle, physically vulnerable, and capable of receiving future actions without deciding those actions in advance.

If this apparatus produces nothing interesting, it should eventually be discarded rather than defended.
